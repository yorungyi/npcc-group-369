# 노스팜CC 연단체 3·6·9

연단체 **후식사 3·6·9 프로모션** 체크와 **연단체 매출 실적**을 휴대폰 한 앱에서 봅니다.
(3회 생맥주 피쳐 · 6회 오늘의 샐러드 · 9회 닭날개&감자튀김 — 연도별로 바꿀 수 있음)

## 화면

| 탭 | 하는 일 |
|---|---|
| **3·6·9** | 야디지북처럼 단체마다 「다음 보상까지 n 번 남음」을 큰 숫자로. 맨 위 **달성 · 지급 체크**(체크 + 메모) → 1번 남음 → 2번 남음 → … 순. 단체를 누르면 보상 이력·방문별 후식 내역 |
| **매출** | 휴대폰용으로 새로 설계: 총매출, 업장별, 월별(누르면 그 달만), 상위·하위 20 비교, 단체 순위(총매출/1인 객단가/클럽하우스). 엑셀 확정 금액만 |
| **자료** | 엑셀 올리기(시트 합계행 대조 후 반영), 확인 필요 목록, 연도별 규칙, 동기화·로그아웃 |

## 카운트 규칙 (`js/promo-core.js`)

- **단체 키** = 예약자명(C열). 단체명(B열)에 「(탈회)」가 한 번이라도 있으면 그 해 그 단체는 탈회 → 프로모션 제외(이력은 보존)
- **후식사 1회** = 대식당 후식 금액 ÷ 인원 **≥ 10,000원**(연도별 설정). 미달은 「제외」로 표시, 자료 탭에서 수동 인정 가능
- **연 단위**(1/1~12/31) 누적, 9회가 끝, 해가 바뀌면 0부터
- 카운트는 **엑셀로만** 갱신됩니다(현장 입력·방문 예정일 추정은 하지 않음 — 2026-10-25 결정)
- 2026-10-25 이전에 달성한 3·6·9는 「앱 도입 전 달성 — 한 번에 정리」로 지급 완료 처리

| 테이블 | 내용 | 쓰는 곳 |

보안: 네 테이블 모두 RLS로 **yorungyiyh@gmail.com 로그인 계정만** 읽고 쓸 수 있습니다. 브라우저에는 공개(publishable) 키만 있습니다.

## 오프라인

- 화면(HTML·CSS·JS·라이브러리)은 서비스워커(`sw.js`)가 휴대폰에 저장 → 전파가 없어도 열림
- 데이터는 마지막으로 받은 사본을 휴대폰에 저장, 지급 체크·메모는 **대기열**에 쌓였다가 연결되면 자동 전송(상단 「대기 n」 표시)
- 로그아웃하면 휴대폰에 남은 사본과 대기열을 지웁니다

## 매달 할 일

1. 월말 엑셀(「단체팀 식음이용현황」 시트)을 받는다
2. 앱 **자료 → 엑셀 올리기** → 7개 합계가 모두 「일치」인지 확인 → **반영**
3. **3·6·9 → 달성 · 지급 체크**에 뜬 단체에 지급했으면 체크
4. **확인 필요**에 뜬 기준 미달 건을 「인정」 또는 「제외 유지」로 정리

## 개발

```bash
npm test
```

- `실행.bat` 또는 `python -m http.server 5179` → `http://localhost:5179/?fixture` 로 열면 로그인 없이 `dev/fixture.json`(엑셀 사본, 저장소 제외)으로 화면 점검. `?fixture=demo` 는 `dev/fixture-demo.json`. 기록은 화면에만 남고 서버로 가지 않음
- 원자료 대조 테스트: 시트를 2차원 배열 JSON으로 내보낸 뒤 `NPCC_SHEET_JSON=경로 npm test`
- 아이콘: `python tools/make_icons.py` · 점검 캡처: `tools/capture.mjs`
- 캐시 구조를 바꾸면 `sw.js`의 `CACHE` 이름을 올리고, CSS·JS 파일명 뒤 `?v=` 숫자도 함께 올린다
- 디자인 기록: `PRODUCT.md`(제품 정의), `.impeccable/surfaces/index-html.md`(디자인 방향)
